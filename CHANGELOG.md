# Changelog

## v0.18.24 — 2026-09-01

### macOS

- Changed the default waveform zoom to 10/11.
- Centered the FX 1 and FX 2 labels.
- Updated the LOOP label typography to match BEATJUMP.
- Highlighted every fourth Traktor beat-grid line to make bar boundaries easier to read.
- Slightly enlarged the artist name.
- Added native pre-fader channel VU meters to Deck A and Deck B.
- Added a native stereo master VU meter on the right side with a 0 dB limiter marker and clip indication.
- Added a standalone macOS installer that downloads the exact pinned v0.18.23 base payload from GitHub when no local payload folder is present, then applies and verifies the v0.18.24 QML changes.

Windows remains on the v0.18.23 cross-platform base package in this release.

## v0.18.23 — 2026-08-24

- Published the complete macOS and Windows distributable base package for Traktor Pro 4.5.0.7.
- Added guided installers and rollback tools for both platforms.
- Added timestamped backups, SHA-256 payload verification, and standalone-display hook checks.
- Added the locally generated macOS Performance Display Launcher for opening the modified Traktor copy.
- Documented the Traktor Kontrol D2 mapping requirement and Windows hardware-test status.
